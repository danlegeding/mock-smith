Python 后端开发实习生 250-300元/天
深圳 | 5天/周 3个月 | 本科

职位描述

职位名称：Python 后端开发实习生（AI 应用方向）

【岗位职责】
1. 参与内部 AI 应用平台的后端开发，负责接口设计、数据建模与业务逻辑实现。
2. 使用 FastAPI 编写 RESTful 接口，对接大模型服务与内部知识库。
3. 参与数据库设计与优化（PostgreSQL），编写数据迁移与批量处理脚本。
4. 配合前端完成联调，参与日志、监控与错误处理的完善。
5. 编写单元测试与接口测试，参与代码评审。

【任职要求】
1. 计算机、软件工程等相关专业在读，能保证每周 4 天以上实习。
2. 熟悉 Python，掌握至少一个 Web 框架（FastAPI / Flask / Django）。
3. 熟悉 SQL，了解索引、事务、连接池等基本概念。
4. 熟悉 Git，能读懂他人代码，有良好的调试习惯。
5. 了解 Docker 的基本使用。

【加分项】
- 有 LLM / RAG 应用开发经验
- 有异步编程经验（asyncio）
- 有开源项目或技术博客
- 用过 Linux 部署服务

【实习安排】
工作地点：深圳南山，每周到岗 4-5 天。
