# AI Agent 开发实习生（样本，用来跑通链路；之后换成你自己找的真实 JD）

**公司/团队**：某 B 端 SaaS 公司 / 智能应用组
**级别**：实习（每周 4 天，3 个月以上）

## 岗位职责

1. 参与 LLM Agent 产品的后端开发，使用 LangGraph / LangChain 编排多步任务流程。
2. 负责通过 FastAPI 对外提供 Agent 能力接口，保证接口稳定与可观测。
3. 参与 RAG 链路的搭建与调优：文档切分、召回、重排、评测。
4. 与产品、算法同学一起做效果迭代，能独立做误差分析并给出改进方案。

## 任职要求

1. 本科及以上在读，计算机 / 软件工程相关专业，能保证每周 4 天到岗。
2. 熟悉 Python，熟悉 FastAPI 或同类 Web 框架，了解异步编程。
3. 使用过 LangChain / LangGraph 等 Agent 框架，理解其状态流转机制。
4. 熟悉 PostgreSQL，能写基本 SQL，了解向量检索（pgvector 等）优先。
5. 熟悉 Docker 基本使用，能自己把服务跑起来。
6. 有 RAG 项目经验，能说清召回率 / 准确率是怎么评估的优先。

## 加分项

- 有完整落地的 AI 应用项目，能讲清架构取舍。
- 了解 LLM 评测方法（人工标注、LLM-as-judge）。
- 有开源贡献或技术博客。
